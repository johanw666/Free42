# Default key mapping table for Free42
#
# Format: [Ctrl|Alt|Shift|CShift|NumPad|NumLock]* <KeyCode> : <macro>
# <KeyCode> is a Free42 key code; <macro> is a sequence of zero or more HP-42S
# key codes. The HP-42S key codes must be between 1 and 255; codes 1..37
# correspond to actual keys on the calculator's keyboard, while codes 38..255
# can be used to refer to extra keys defined by customized skins.
#
# The Free42 key codes are:
#
# A..Z 0..9 SPACE TAB ENTER ESC F1..F20
# ADD SUBTRACT MULTIPLY DIVIDE EQUALS
# GRAVE LEFT_BR RIGHT_BR QUOTE PERIOD COMMA SEMICOLON BACKSLASH
# BACKSPACE CLEAR INSERT DELETE HOME END PRIOR NEXT
# UP DOWN LEFT RIGHT
#
# Ctrl, Alt, Shift, and NumLock refer to the corresponding modifier keys.
# CShift refers to the state of the Calculator's Shift annunciator. This
# modifier makes it possible for [CShift] [Key] to activate a different
# keystroke or macro than the unshifted [Key], so you can, for example, make
# CShift SQRT be something other than X^2.
# NumPad indicates a key on the numeric keypad.
# Keystrokes with NumPad, NumLock, or CShift may be matched with key mappings
# without some or all of these modifiers, if no exact match is found. If
# multiple inexact matches are found, mappings with matching NumPad modifiers
# get the highest priority, followed by NumLock and CShift.
#
# Anything from a "#" until the end of the line is a comment, and is ignored.
# White space (Space, Tab) separates tokens in the key map, but is otherwise
# ignored.
